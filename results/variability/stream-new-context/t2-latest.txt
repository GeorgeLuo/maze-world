Phenomena:
- traverser_navigation: multiple traversers explore the maze using individual algorithms; some can branch into duplicates sharing a global visited-memory during search

Dimensionalities:
- maze_width: maze width in cells (current: 11)
- maze_height: maze height in cells (current: 11)
- traverser_positions: locations of all traversers in maze coordinates (current: unspecified)
- traverser_count: number of traversers present in the maze (current: unspecified)
- traverser_algorithms: algorithm associated with each traverser (current: unspecified)
- traverser_map_knowledge: extent of each traverser's knowledge of the maze layout (current: none initially)
- branch_search_capability: which traversers can branch into duplicates during search (current: subset unspecified)
- branch_duplicate_count: number of active duplicates spawned by branching-capable traversers (current: unspecified)
- shared_visited_memory: global memory of maze locations visited by branching-capable traversers (current: shared across duplicates)
